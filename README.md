# Projeto Jurandi

Relatório técnico do desenvolvimento do catamarã autônomo Jurandi, uma plataforma de superfície criada na Universidade Federal da Paraíba com apoio da CAPES.

**Site publicado:** https://laser-robotics.github.io/laser_jurandi_report/

## Conteúdo

A documentação apresenta objetivos, materiais, construção, integração eletrônica, configuração de firmware, testes e resultados do projeto.

## Editar e visualizar localmente

1. Instale o Python 3.10 ou superior.
2. Instale as dependências: `python -m pip install -r requirements.txt`
3. Gere o site: `make html`
4. Abra `build/html/index.html` no navegador.

Os textos estão em `source/` e as imagens em `source/images/`. Um envio para a branch `main` publica automaticamente a nova versão pelo GitHub Pages.
